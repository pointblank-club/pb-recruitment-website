# Contributing to pb-recruitment-website

Thank you for considering contributing to the Point Blank Club Recruitment Website! We welcome all types of contributions, including bug fixes, enhancements, documentation, tests, or suggestions.

## How to Contribute

1. **Fork the repository** and clone your fork locally.
2. **Create a new branch** for your feature or bugfix:
   ```bash
   git checkout -b my-feature
   ```
3. **Commit your changes** with descriptive commit messages.
4. **Push to your fork**:
   ```bash
   git push origin my-feature
   ```
5. **Open a Pull Request** describing your changes in detail.

## Guidelines

- Follow the code style used currently in the project.
- Include tests when adding new features or fixing bugs (if applicable).
- Write clear, concise commit messages.
- Keep pull requests focused—avoid bundling unrelated changes.

## Code of Conduct

Everyone is expected to adhere to our project's [Code of Conduct](CODE_OF_CONDUCT.md) (if available) to foster an open and welcoming community.

## Reporting Issues

If you find a bug or want to request a feature, please [open an issue](https://github.com/pointblank-club/pb-recruitment-website/issues) and provide relevant details.

## Need Help?

If you have any questions, open an issue or start a discussion in the repository.

Happy coding!
